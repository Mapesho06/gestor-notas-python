# 📝 Gestor de Notas en Python

Aplicación CLI (Command-Line Interface) desarrollada en Python para la creación, consulta, búsqueda y mantenimiento de notas en memoria.

## 🚀 Funcionalidades

- **CRUD de notas:** Creación de entradas, edición por sobrescritura de notas existentes y borrado mediante selección indexada.
- **Búsqueda textual:** Filtrado por coincidencia de subcadenas en títulos y contenidos sin distinción entre mayúsculas y minúsculas (`case-insensitive`).
- **Métricas y estadísticas:** Cálculo del total de registros y estimación de longitud media de contenido por nota.
- **Robustez:** Validación de entradas numéricas con bloques `try...except` para captura de `ValueError` y confirmación de operaciones destructivas.

## 🛠️ Tecnologías

- **Python 3**
- Estructuras de datos nativas (`list`, `dict`)
